# 📦 حزمة النشر والمساعد التنفيذي لنظام DMS (DMS Deployment Toolkit)

تم إنشاء هذه الحزمة لتحويل **[دليل التجربة من الصفر](..\خطط\دليل%20التجربة%20من%20الصفر%20—%20حاسبة%20تجريبية.md)** إلى منظومة عمل تفاعلية ذكية ومؤتمتة بالكامل، للقضاء على الأخطاء اليدوية والخلط بين الأجهزة.

---

## 🗂️ محتويات الحزمة

| الملف / المجلد | الوصف والدور |
|---|---|
| 📑 **`DMS_Deploy_Wizard.html`** | الكتالوج الرسومي التفاعلي الشامل (يفتح في أي متصفح، مولّد الأوامر اللحظي، فلاتر الأجهزة). |
| ⚡ **`Launch_Wizard.bat`** | ملف تشغيل سريع: انقر عليه مرتين لفتح الكتالوج في متصفحك الافتراضي فوراً. |
| 💻 **`Run_Console_Menu.bat`** | قائمة تفاعلية في PowerShell لتشغيل أي خطوة من 0 إلى 8 بمجرد كتابة رقمها. |
| 📁 **`scripts\`** | مجلد السكربتات المؤتمتة الكاملة (مبنية ومتوافقة 100% مع Windows PowerShell 5.1). |

---

## 📜 السكربتات المرقمة (`scripts\`)

1. **`00-reset-trial.ps1` (تصفير الحاسبة التجريبية):**
   * يحذف خدمات `DmsApi` و `Cloudflared`.
   * يستعيد موقع IIS الافتراضي ويشغله.
   * يحذف قاعدة `DmsTrial` ويفرغ مجلد `C:\DMS`.
   * يعيد حاسبة التجربة إلى وضع النظافة التامة للتجربة من الصفر.

2. **`01-dev-build-and-pack.ps1` [💻 جهاز التطوير]:**
   * يبني الباك-إند `.NET API`.
   * يبني الواجهة مع الدومين المخبوز داخل `main.dart.js`.
   * يفحص الحراس الصارمين (وجود الدومين، وجود سكربت التحديث، وعدم تسريب ملف التطوير).
   * يضغط الحزم إلى مجلد النشر ويفحص أن الحجم > 5 ميغابايت.

3. **`02-trial-unpack.ps1` [🧪 حاسبة التجربة]:**
   * يتعرف تلقائياً على محرك الفلاشة أو المسار المحدد.
   * يفرغ مجلد الواجهة قبل فك الضغط لتجنب تراكم الملفات القديمة.
   * يفك ضغط `dms-api.zip` و `dms-app.zip` إلى `C:\DMS`.

4. **`03-trial-preflight.ps1` [🧪 حاسبة التجربة]:**
   * الفحص المسبق السريع ومسبار الدوت نت الحقيقي `generate-secrets` (حل العطل 3).
   * فحص منافذ 80 و 5080 ومثيل SQL Server.

5. **`04-trial-secrets-and-db.ps1` [🧪 حاسبة التجربة]:**
   * إنشاء مجلدات التخزين والنسخ وضبط أذونات محرك SQL.
   * توليد الأسرار `generate-secrets` وقفل أذونات الملف.
   * **[حل العطل 4]:** منح صلاحية `sysadmin` لحساب `NT AUTHORITY\SYSTEM` قبل الإقلاع.
   * أول إقلاع للمهاجرات وفحص الدخول المحلي على 5080 لعزل المتغيرات.

6. **`05-trial-service-setup.ps1` [🧪 حاسبة التجربة]:**
   * تسجيل الخدمة `DmsApi` مع ضبط التبعية لمثيل SQL وخطة التعافي التلقائي.
   * حقن `ASPNETCORE_ENVIRONMENT=Production` في السجل.
   * تشغيل الخدمة والتحقق من الرد.

7. **`06-trial-iis-setup.ps1` [🧪 حاسبة التجربة]:**
   * **[حل العطل 9]:** إيقاف وتعطيل الإقلاع التلقائي للموقع الافتراضي `Default Web Site`.
   * إنشاء وضبط موقع `DmsApp` على المنفذ 80.
   * فحص ملفات WASM و `canvaskit.wasm` لضمان عدم ظهور الشاشة البيضاء.

8. **`07-trial-tunnel-setup.ps1` [🧪 حاسبة التجربة]:**
   * تثبيت `cloudflared` والتوثيق وإنشاء النفق.
   * ضبط قواعد التوجيه في `config.yml` (الـ API إلى 5080 والواجهة إلى 80).
   * **[حل العطل 7]:** نقل إعدادات النفق لحساب `SYSTEM` وتصحيح `ImagePath` في السجل لتفادي خروج الخدمة صامتاً.
   * تشغيل النفق كخدمة ويندوز مستقرة.

9. **`08-trial-verify-final.ps1` [🎯 فحص شامل]:**
   * فحص الخدمات الثلاث (`Cloudflared, DmsApi, W3SVC`) ومواقع IIS.
   * فحص استجابة الـ API والواجهة عبر الدومين الخارجي.
   * تقديم خطوات الاختبار الحاسم وجائزة التجربة (ختم الـ QR).

## 🚀 كيفية الاستخدام:

### على جهاز التطوير:
1. افتح المجلد `D:\DMS\DMS-Toolkit`.
2. شغّل `Launch_Wizard.bat` لاستعراض الكتالوج الرسومي، أو `Run_Console_Menu.bat` لتنفيذ المرحلة 1.
3. انقل ناتج النشر (`dms-api.zip` و `dms-app.zip`) مع مجلد `DMS-Toolkit` إلى الفلاشة.

### على حاسبة التجربة:
1. لتصفير الحاسبة التجريبية: شغّل الخيار [0] أو `00-reset-trial.ps1`.
2. نفذ المراحل بالتتابع من 2 إلى 8 إما عبر القائمة التفاعلية `Run_Console_Menu.bat` أو بنسخ الأوامر من `DMS_Deploy_Wizard.html`.
