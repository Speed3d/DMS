## 6) ما تبقّى — مرتّباً بالأثر

> 📋 البنود الحرجة والعالية صارت **خطة تنفيذ تفصيلية**: [`deployment-plan.md`](deployment-plan.md)

### 🔴 حرجة (تمنع التسليم)
- **استعادة النسخة الاحتياطية** (G1) — تزداد أهمية مع السيرفر الداخلي: لا مزوّد سحابي يتدخّل نيابةً عنّا.
- **سياسة الاحتفاظ بالنسخ + فصل القاعدة عن الملفات** (G6) — بدونها يمتلئ التخزين السحابي.
- **تنفيذ خطة النشر** — شراء الجهاز · الدومين · النفق · التشغيل.

### 🟠 عالية
- تشغيل الـ API **كخدمة ويندوز** (يبدأ مع الإقلاع ويتعافى من التعطّل).
- تأمين الأسرار: BitLocker + NTFS + **مفاتيح إنتاج جديدة** (G4).
- مثبّت ويندوز `.exe` (G5).
- اختبارات العزل الصفّي والتزامن (G2).

### 🟡 متوسطة
- تقارير النشاط (من سجل التدقيق) والتقارير التفصيلية للصادر والأرشيف.
- عارض PDF داخل الوارد والأرشيف (موجود في الصادر فقط — والوارد أولى به لأنه صور ممسوحة).
- لوحة التحكم: قائمة «آخر الوارد» + إدراج الوارد في الرسم البياني الأسبوعي.

### ⚪ لاحقة
- مراقبة مجلد مخرجات السكنر.
- تقارير ولوحات متقدمة.
- نسخة ويب/هاتف (اطلاع + اعتماد + مسح QR بالكاميرا).

### مؤجَّلات صغيرة من وحدة الوارد
- ربط الصادر بالوارد **أثناء إنشاء الصادر** (حالياً من شاشة الوارد فقط).
- منح **مدراء محدّدين** رؤية سجل الحركة (حالياً السوبر أدمن ورئيس الشركة فقط) — يتطلب صلاحية جديدة على المستخدم.
- **رؤية المحوَّل للأقسام:** الإحالة نصّ حر، فتحويل كتاب لـ«المالية» لا يجعله مرئياً لموظفي المالية (المدراء يتابعون). الحل الكامل يتطلب جدول أقسام أو إسناد لمستخدم.

## 7) تشغيل النظام

```bash
# الخادم (نافذة أولى) — المنفذ 5080 ثابت
cd D:\DMS\backend
dotnet run --project Dms.Api

# الواجهة (نافذة ثانية)
cd D:\DMS\app
flutter run -d chrome
```

- **قاعدة البيانات:** SQL Server المثيل الافتراضي (`Server=.`)، قاعدة `DmsDb`.
  ⚠️ أدوات `dotnet ef` تقرأ `appsettings.json` (إعدادات الإنتاج) فتفشل بخطأ TCP — للفحص السريع استخدم:
  `sqlcmd -S . -E -d DmsDb -I -Q "..."` (الخيار `-I` ضروري مع الجداول ذات الفهارس المفلترة).
- **الأسرار:** `backend/Dms.Api/appsettings.Development.json` (غير مُدرج في git).
- **أوقف الـ API قبل إعادة البناء** — يقفل ملفات الإخراج.

### اختبار التدفق الشامل
```bash
powershell -File backend\e2e\incoming-e2e.ps1 -AdminPwd <pwd> -EmployeeUser sinan -EmployeePwd <pwd>
```
65 تحقّقاً، قابل لإعادة التشغيل. النجاح = `فشل: 0`.
⚠️ ملفات PowerShell بالعربية تحتاج ترميز **UTF-8 with BOM** وإلا فشل التحليل النحوي في PS 5.1.
