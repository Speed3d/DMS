## ✅ Phase 2 — الأمان والتحسينات المتقاطعة (Security & Cross-platform)
- [x] **التدقيق الأمني (مكتمل):** حماية الجلسات وتشفيرها عبر `flutter_secure_storage`، إخفاء كلمات المرور (Secrets) من الإعدادات، تفعيل سياسات CORS مشددة، وحماية ضد هجمات Path Traversal.
- [x] **تحديث التوافقية:** ترقية بيئة Dart إلى `3.12.0` وتفعيل سياسة `LatestMajor` للـ .NET لضمان توافقية التشغيل السلس بين أنظمة Windows و Mac.
- [x] **الأرشيف (مكتمل):** باك-إند (ArchiveService + AttachmentService) + Controllers + واجهة كاملة — حقول + مالي + ترقيم تلقائي (`DEN-AR-2026-00001`) + **مرفقات (رفع/تنزيل/حذف، PDF/JPG/PNG/DOCX/XLSX، حد 25MB)** + **بحث نصّي وبفترة زمنية**. اجتاز E2E (إنشاء/بحث/مرفق/تنزيل/حذف).
- [x] **التقرير المالي بالدينار (مكتمل):** يجمع الصادر المعتمد + الأرشيف لفترة، تصفية (تاريخ/جهة/مصدر)، إجمالي بالدينار، **تصدير PDF (QuestPDF) و Excel (OpenXML)** + شاشة بالواجهة. اجتاز E2E.
- [x] **النسخ الاحتياطي (مكتمل):** تحكّم السوبر أدمن — نسخة فورية + جدولة (يومي/أسبوعي بساعة) + خدمة خلفية `BackupScheduler` + سجلّ + تنزيل. النسخة = `BACKUP DATABASE` (.bak) + ملفات التخزين في ZIP واحد. اجتاز E2E (4.5MB، يحوي database.bak + 13 ملفاً). (رفع OneDrive عبر Graph مؤجَّل — يكفي التنزيل/النسخ اليدوي حالياً.)
- [x] **وضع المسودّات دون اتصال والمزامنة (مكتمل):** استخدام قاعدة بيانات Hive لحفظ المسودات والبيانات المخبأة محلياً (Cache) لدعم بيئة Windows بأمان، مع شاشة خاصة للمزامنة الجماعية عند عودة الاتصال.
