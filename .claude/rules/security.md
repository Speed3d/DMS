# قواعد: الأمان

## المصادقة
- JWT (HMAC-SHA256) + Refresh token (مجزّأ في DB، مع **تدوير** عند كل تجديد).
- كلمات المرور: **BCrypt** (workFactor 12). لا تُخزَّن أو تُسجَّل كلمة مرور خاماً أبداً.
- قفل مؤقت بعد 5 محاولات فاشلة (15 دقيقة). أول دخول يُجبر تغيير كلمة المرور.

## الصلاحيات (هرمية)
- كل مستوى يدير **الأدنى منه فقط** (`RoleHierarchy.CanManage`). لا تعديل لمن في نفس المستوى أو أعلى.
- الاعتماد: المدير فأعلى، أو `CanApprove`، أو تفويض نشط (`EffectiveCanApprove`).
- التعديل بعد الاعتماد: المدير فأعلى + سجل إصدار + تزامن متفائل (`RowVersion`).
- **إنشاء الشركات/رموز الترقيم: SuperAdmin فقط** (التعديل لرئيس الشركة فأعلى) — تشديد مقصود لمصفوفة الخطة لأسباب أمنية.
- الموظف/القارئ يرى عمله فقط في الصادر.

## العزل والبيانات
- لا تتجاوز العزل الصفّي حسب الشركة. أي استعلام عبر `AppDbContext` يُفلتَر تلقائياً.
- الحذف **ناعم دائماً** (`IsDeleted` + `DeletedBy/DeletedAt`) — لا حذف فعلي.
- كل عملية حسّاسة (إنشاء/تعديل/حذف/اعتماد/دخول) تُسجَّل في **سجل التدقيق**.

## الأسرار
- مفاتيح JWT و QR (ECDSA) في `appsettings.Development.json` للتطوير فقط (**غير مُدرج في git**).
- في الإنتاج: **Azure Key Vault**. لا تضع أسراراً في الكود أو في `appsettings.json` المُدرج.

## المرفقات
- تحقّق من النوع (PNG/JPEG للصور) والحجم. لا تكشف Blob مباشرةً — الوصول عبر الـ API مع تحقق الصلاحية.

## الإنتاج
- HTTPS إلزامي. اختر منطقة Azure قريبة (UAE/أوروبا). فعّل App Insights.
